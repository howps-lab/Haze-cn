# 新加坡实时烟霾监测 (Singapore Real-Time Haze Monitoring)

功能完整、移动端响应式的新加坡官方实时烟霾与空气质量监测 Web App，采用纯简体中文界面。

## 一、数据来源与真实性保障

- **官方主要数据来源**：新加坡国家环境局 (NEA) 官方烟霾网站 (https://www.haze.gov.sg/) 与 Data.gov.sg 官方开放 API：
  - `https://api.data.gov.sg/v1/environment/pm25` (1小时 PM2.5 浓度，微克/立方米 µg/m³)
  - `https://api.data.gov.sg/v1/environment/psi` (24小时 PSI 污染标准指数及各项附属污染物子指标)
- **绝无虚构数据**：所有读数均直接追溯至官方发布接口。当网络断开或官方维护时，应用明确提示“暂时无法获取官方数据”，并保留最近一次成功获取的有效数据及具体更新时间。

## 二、核心功能与特性

1. **全简体中文界面**：包括页面标题、时钟时区、数据标签、图表、状态提示、分级说明及法律免责声明。
2. **实时动态新加坡时钟**：每秒更新当前日期、星期与时间，使用 24 小时制及新加坡标准时区（Asia/Singapore，UTC+8）。
3. **双通道数据获取与智能刷新**：
   - 页面加载后立即获取最新数据。
   - 每 60 秒自动检查更新（提示用户以官方实际每小时/每15分钟发布频率为准）。
   - 页面由后台切回前台时，自动重新检查并刷新。
   - 网络恢复时自动重新拉取。
   - 支持手动“立即更新”按钮，配备实时加载反馈。
4. **五大区域地理卡片网格**：
   - 涵盖官方设立的五大监测区域：北部 (North)、南部 (South)、东部 (East)、西部 (West)、中部 (Central)。
   - 支持按指数由高到低、由低到高及默认区域排序。
   - 支持展开查看官方发布的附属监测子指标（PM10 24小时、O3 臭氧、CO 一氧化碳、SO2 二氧化硫）。
5. **历史变化趋势图表**：
   - 整合官方连续时序数据，提供近 6小时、12小时、24小时、48小时多时间跨度。
   - 支持全岛五区对比或单独查看指定区域。
   - 中文坐标轴与触摸悬停数据详情提示。
6. **官方健康防护指南**：
   - 区分一般健康公众与易感群体（老人、孕妇、儿童及患有心肺疾病人士）的防护建议。
   - 详细呈现 1小时 PM2.5 四级标准与 24小时 PSI 五级标准的对照表格。
7. **移动优先响应式设计**：
   - 手机端采用单列自适应卡片。
   - 平板与桌面端采用多列网格与比例均衡的仪表板布局。
   - 提供平滑返回顶部悬浮按钮。

## 三、本地安装与运行

```bash
# 1. 安装项目依赖
npm install

# 2. 启动开发服务器（端口 3000）
npm run dev

# 3. 生产环境打包构建
npm run build
```
